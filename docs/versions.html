The 34 module jars

macroEngine ships as one core jar and 33 module jars - 34 artifacts in total, from modules.json. Every module declares macroengine-core as a dependency and every one installs alone next to the core; that is checked by a test, not assumed. They are Fabric mods that also work as plain data packs, at pack format 121.0.

A two-part pack format (121.0) is the 26.x format, which carries a minor number. Single numbers predate it. A pack whose format is well below the one your server expects will not load without being rewritten - the version column is what it was written against, not a compatibility claim.

The jump from 41 to 97 is not a missing row: the format numbering restarted its scheme when Minecraft's versioning changed. That is also why 26.x formats carry two parts.

If a pack does not load

The usual cause is the pack format, not the content. Change pack_format in pack.mcmeta to the number your server expects and it will usually load, because the function syntax changed far less than the number suggests. It is still an archived pack - loading is not the same as working, and the warning is there for a reason.
