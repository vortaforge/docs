Archive

Every project VortaForge has retired, with its last version, the Minecraft release it targeted and the reason it stopped.

32 projects are registered here and all of them are retired. 11 datapacks, one resource pack, 16 scripts and 1 mod form the rest. This page exists so that "what happened to X" has an answer, not so that X is worth installing.

The rule behind the table

Retirement is recorded, not deleted. Deleting a project removes the only evidence that it existed, which makes an old world's missing scoreboard holder impossible to explain a year later. So each project gets a row: what it was, what it targeted, and what replaced it if anything did.

Two consequences worth stating plainly:

  • Archived does not mean broken. Several of these still load on the version they targeted. They are unsupported, which is a different claim.
  • A row is not a recommendation. The reason field is the interesting one, and it is almost never "it was bad" - usually the Minecraft feature it patched around shipped natively, or the mod superseded it.

Why things were archived

ReasonWhat it meansTypical case
Superseded by a mod A Fabric mod now does the same job with less maintenance, because a mod is not re-tested against every datapack format change. macroEngine the datapack → macroEngine the 34-module mod set
Vanilla absorbed it Minecraft shipped the feature, so the workaround became a smaller, worse version of the thing itself. A pack that emulated a game rule the release then added
Retired with its host The pack only made sense alongside another pack. Both stop, or the supported half becomes unreachable. macroEngine's resource pack (i18n, sounds, trim assets)
Never a deliverable A test harness, a generator or a one-off that was useful during development and has no user. Scripts and tooling in the rows above
