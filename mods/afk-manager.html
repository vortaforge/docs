afk-manager

Marks a player as AFK after a period of no movement, announces it, and optionally kicks them. Every value has a clamp, and the clamps are listed here because the defaults alone do not tell you what the mod will do with a value you set yourself.

What it actually does

On each server tick the mod samples each online player's position. When the samples stop changing for afkAfterSeconds, the player is treated as AFK. If announce is on, that is said in chat. If kickAfterSeconds is greater than zero and the player stays AFK that long, they are disconnected with kickMessage.

The timer resets on movement, not on any other activity. A player standing perfectly still with their inventory open is AFK by this definition; a player walking in a one-block square forever is not.

Installation

  1. Drop the jar in mods/. It needs Fabric Loader and nothing else - Fabric API is not a dependency.
  2. Start the server once. config/afk-manager.json is created with the defaults below.
  3. Edit it and restart, or leave the defaults and use /afk.

If a value is missing from the file it is filled from the default. If a value is present but out of range it is clamped, not rejected: the server still starts, and the effective value is what the clamp produced.

The /afk command

One command, no arguments:

/afk

It marks the sender as AFK immediately, without waiting for afkAfterSeconds. That is the whole surface - there is no /afk status, no target argument and no way to mark someone else.

Settings, with their clamps

KeyDefaultRange / clampWhat it does
afkAfterSeconds300 10 – 86,400 Seconds without movement before a player counts as AFK. Values below 10 are raised to 10; above 86,400 are lowered to 86,400.
kickAfterSeconds0 0, or at least afkAfterSeconds – 604,800 0 means never kick. Any positive value below afkAfterSeconds is raised to it, because kicking someone before they are AFK is not a meaningful setting. The cap is seven days.
announcetrue boolean Say in chat when a player goes AFK. Turning this off does not affect the kick timer.
exemptOperatorsFromKicktrue boolean Operators are never kicked, but they are still marked and announced. Set to false if an idle operator should be removed.
kickMessage"Kicked for being AFK." max 200 characters The disconnect reason. A blank or missing value falls back to the default; longer values are cut at 200.

Choosing values

Survival, no kicks

{
  "afkAfterSeconds": 300,
  "kickAfterSeconds": 0,
  "announce": true
}

The default. Nobody is removed; the chat note is informational. Use this when the server does not need the slot back.

Small server, reclaim slots

{
  "afkAfterSeconds": 180,
  "kickAfterSeconds": 600,
  "announce": true,
  "exemptOperatorsFromKick": true
}

Three minutes to AFK, ten minutes to kick. Operators stay. This is the setting that stops one idle player from holding the last slot all night.

Keep the tab list honest

{
  "afkAfterSeconds": 60,
  "kickAfterSeconds": 0,
  "announce": true
}

One minute is short enough that the announcement is genuinely useful and long enough that reading a sign does not trigger it.

How the timer works

The check runs every server tick, not on a wall clock. That has three consequences worth knowing:

  • A tick that takes 200 ms ages the AFK timer by one tick, not by 200 ms. On a lagging server, players go AFK later than the configured time in real seconds.
  • Stopping the server stops the timer. A restart does not resume an in-progress AFK period; the sample resets.
  • Teleporting counts as movement. A player moved by a plugin or a portal is not AFK afterwards.

What it does not do

  • It does not read chat. Talking while standing still stays AFK. That is deliberate - typing is not moving - but it surprises people.
  • It does not persist AFK state. Nothing is written to disk about who was AFK.
  • It does not change the player list. No [AFK] prefix, no tab-list colour, no scoreboard. Announcement is a chat line.
  • It has no permission node. /afk is available to everyone, which is the point of it.
This page describes the shipped defaults and clamps. They are read from AfkSettings: afkAfterSeconds = 300, kickAfterSeconds = 0, announce = true, exemptOperatorsFromKick = true, and a 200-character cap on the message. If a build you are running disagrees, the build is right and this page is out of date.
