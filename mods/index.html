Mods

Two Fabric mods, both for Minecraft 26.3, both small enough to read in an afternoon. Neither needs Fabric API.

afk-manager

Marks players AFK after a period without movement, announces it, and optionally kicks them.

join-throttle

Installing either mod

  1. Install Fabric Loader for Minecraft 26.3. Java 25 is required, not 21 - Mojang's version metadata for 26.3 names 25, and a 21 runtime will not start.
  2. Put the jar in mods/, next to the loader.
  3. Start the server once. The config file appears under config/ with the defaults filled in.
  4. Edit and restart. Neither mod reloads its config live; a restart is the only way to apply a change.
Fabric API is not required. Both mods are deliberately self-contained. If you already run Fabric API for something else, that is fine - it just is not a dependency, and removing it from mods/ will not break either one.

Reading a settings file

Both files are flat JSON: one object, no nesting, keys as shown on each mod's page. Parsing rules that apply to both:

  • A missing key gets its default. Deleting a line is a valid way to restore one value.
  • An out-of-range value is clamped, not rejected. The server starts, and the effective value is what the clamp produced. Each page lists the clamp.
  • A malformed file is not silently ignored. If the JSON does not parse, the mod says so in the log rather than quietly running on defaults - a typo should be visible.
  • Nothing is written back. The mod reads the file; it does not rewrite it with your values clamped, so what you wrote stays what you wrote.

Neither mod is a security boundary

join-throttle slows a reconnection loop; it does not stop a distributed one. afk-manager frees a slot; it does not authenticate anyone. Both are convenience for a server you already trust, and neither should be the reason an untrusted client is allowed in.
